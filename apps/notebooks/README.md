# Notebook: final_visualizations.ipynb

`final_visualizations.ipynb` is the Python visualization deliverable of the project. It reads the flat table built by the ETL pipeline, answers the business question (*how much does missing the promised delivery date cost Olist, and where does it happen?*) with one visual per data class, cross-checks its KPIs with the reference of the Power BI dashboard and prints the figures of the narrative arc that [`docs/06-storytelling.md`](../../docs/06-storytelling.md) quotes.

| File | What it is |
| :-- | :-- |
| `final_visualizations.ipynb` | The notebook, versioned with its outputs (executed) |
| `final_visualizations.py` | Script twin of the notebook, generated by the launcher with `nbconvert --to script` (without cell prompts or header lines); never edit it by hand |

## Requirements

- The environment of [`docs/08-setup-and-run.md`](../../docs/08-setup-and-run.md): `pip install -r requirements.txt` also installs the local `ecbd_viz` package (`-e packages/viz-kit`) with the palettes, the Matplotlib style and the Plotly template.
- The inputs: `data/processed/analytics_flat.csv.gz` (built by `python scripts/run_pipeline.py`, already versioned), `data/reference/brazil-states.geojson` and `apps/bi-dashboard/validation/kpi_reference.csv` (written by `python scripts/kpi_reference.py`, already versioned). If one of them is missing, the setup cell stops with a message that names it.

## Running

Every command is run from the repository root, with the virtual environment active.

| Option | Command | Result |
| :-- | :-- | :-- |
| Launcher (recommended) | `python scripts/run_notebook.py` | Executes the notebook in place, regenerates the script twin and runs the final checks (ASCII, twin, exports and SVG text); exit code 0 only if every check passes |
| Checks only | `python scripts/run_notebook.py --check-only` | Runs the final checks without executing the notebook |
| Jupyter | `jupyter notebook`, open `apps/notebooks/final_visualizations.ipynb` and choose *Kernel > Restart & Run All* | Same outputs; then run `python scripts/run_notebook.py` so the twin stays in sync |
| Script twin | `python apps/notebooks/final_visualizations.py` | Runs the same code without Jupyter and writes the same exports |

The twin is regenerated by the launcher as its last writing step; the check `check_twin` fails if the versioned `.py` differs from the notebook.

## Offline limitation

The HTML files embed plotly.js, so 08, 09, 10 and 15 show their data without an internet connection. The maps 11, 12 and 13 draw the state outlines of the embedded GeoJSON and use no map tiles; they were not tested without a connection, so they may still depend on geographic layers that Plotly downloads. This is a known limitation. For an offline presentation, use the static backups:

| Interactive | Static backup |
| :-- | :-- |
| `11_choropleth_orders_per_100k.html`, `12_choropleth_delay.html`, `13_density_customers.html` | `14_geo_rank_states` (static geographic view) |
| `08_scatter_distance_freight.html` | `08s_scatter_distance_freight` |
| `09_bubble_category_delay_review.html` | `09s_bubble_category_delay_review` |
| `15_polar_hour.html` | `15a_polar_orders_by_hour`, `15b_polar_orders_by_weekday` |

GitHub does not render the Plotly outputs of the `.ipynb`; open the HTML files in `outputs/interactive/` or run the notebook locally to see them.
