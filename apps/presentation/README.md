# Executive presentation — `apps/presentation`

Deliverable 3 of the final project: the executive deck of the Phanex study, structured around the
data storytelling arc (Setup, Conflict, Resolution).

| File | What it is |
| :-- | :-- |
| `IT91_Phanex_Final_Project_Presentation_ECBD.pptx` | **The deliverable.** 16 slides, 16:9 |
| `IT91_Phanex_Final_Project_Presentation_ECBD.pdf` | The same deck exported to PDF, for the submission and as the backup of the talk |

Only the deck lives here. The team template, the slide text and the speaker notes are local
working material and are not versioned: from this point the deck is edited in Canva by the team,
so a copy of its text inside the repository would soon disagree with the real presentation.

Every information slide carries one visual on the left and its text on the right. The visuals are
the figures of [`final_visualizations.ipynb`](../notebooks/final_visualizations.ipynb) and two

on screen was drawn only for the talk. Every figure in the text comes from
[`../../docs/06-storytelling.md`](../../docs/06-storytelling.md) with the same value and rounding.

## Typography and limits

Poppins for the slides: 72 pt for a section title, 30 pt for a slide title, 16 pt for body text
and for the sources. The cover keeps the fonts of the template. The rules of the layout, the colors and the limits that keep the text inside
its frame are in [`../../docs/05-design-system.md`](../../docs/05-design-system.md).
